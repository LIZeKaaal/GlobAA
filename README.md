# GlobAA

Source code and numerical experiments for GlobAA, a nonmonotone globalization
framework for Anderson acceleration. The experiment directories correspond to
Sections 3.1–3.4 of the accompanying paper and cover a fixed-point
counterexample, elastic-net regression solved with ISTA, a nonlinear Helmholtz
problem, and a Navier–Stokes cavity problem.

Maintainer: **lizekai**.

## Repository layout

| Path | Purpose |
| --- | --- |
| `Anderson.py` | Anderson acceleration and FAA coefficient/history handling |
| `optim_algo.py` | Fixed-point iteration framework and `GlobalAndersonSolver` |
| `lsqr.py` | Upstream PyTorch LSQR implementation |
| `3.1_counterexample/` | Counterexample and gamma-schedule experiments |
| `3.2_ENR_ISTA/` | ENR/ISTA experiments with Madelon and a synthetic ill-conditioned matrix |
| `3.3_NLH/` | Nonlinear Helmholtz experiments |
| `3.4_NS/` | Three separately computed Navier–Stokes experiments |
| `datasets/ISTA/` | Madelon training data and dataset attribution |

The experiment directories include saved results and figures. Numerical runs
and plotting are separate, so the supplied results can be plotted without
repeating the full solver runs.

## Environment

The reference environment is **Python 3.9.18 on macOS ARM64**, with CPU
computation and `float64` arithmetic:

| Package | Version |
| --- | --- |
| NumPy | 1.26.3 |
| SciPy | 1.11.4 |
| PyTorch | 2.8.0 |
| Matplotlib | 3.7.5 |
| scikit-fem | 11.0.0 |

From the repository root (the directory containing this README), create an
environment and install the direct dependencies:

```bash
conda create -n globaa python=3.9.18 pip
conda activate globaa
python -m pip install -r requirements.txt
```

Use the pinned dependencies, CPU computation, and `float64` arithmetic to
reproduce the documented experiments. The finite-element Navier–Stokes solver
uses NumPy, SciPy, and scikit-fem on the CPU.

Before plotting, set a writable Matplotlib cache directory. In a macOS/Linux
shell:

```bash
export MPLCONFIGDIR="$PWD/.matplotlib"
```

In PowerShell:

```powershell
$env:MPLCONFIGDIR = Join-Path (Get-Location) ".matplotlib"
```

The local cache directory is excluded by `.gitignore`.

## Short example runs

Run these commands from the repository root. They write to the ignored
`scratch/` directory rather than replacing the supplied results:

```bash
python 3.2_ENR_ISTA/run_ENR_ISTA.py --smoke --dtype float64 --device cpu --output-dir scratch/enr_smoke
python 3.3_NLH/run_NLH.py --N 101 --m-values 1,3 --max-iters 5 --output-dir scratch/nlh_smoke
python 3.4_NS/run_NS.py --base-points 4 --no-edge-refine --re 5000 --m-values 3 --max-iters 5 --output-dir scratch/ns_smoke
```

ENR smoke mode runs both cases with `m=1` and five iterations. It retains the
full matrix dimensions, including matrix construction and spectral
calculations. These short runs help check an installation; use the full
commands below to reproduce the paper's experiments.

## Reproduce the experiments

All commands below assume the repository root as the working directory.
Experiment and plotting commands overwrite generated files in their output
directories. To preserve the supplied results, choose a separate
`--output-dir` where supported; the gamma-schedule script instead accepts an
`--output` CSV path. Plotting scripts with `--input` or `--input-dir` options
can then read the new results. Run a numerical script with `--help` to see its
options.

### 3.1 Counterexample

```bash
python 3.1_counterexample/run_counterexample.py --dtype float64 --device cpu
python 3.1_counterexample/plot_counterexample.py
```

The numerical script produces the three CSV files for the initial values
`t0=2.1`, `t0=300`, and the `m=3,5` comparison. The plotting script reads these
files and writes the corresponding PDFs under `3.1_counterexample/figures/`.
The figure runs record up to 50 iterations, matching the plotted window.

The additional gamma-schedule experiment is run separately:

```bash
python 3.1_counterexample/run_gamma_sweep.py --dtype float64 --device cpu
```

It writes `3.1_counterexample/results/gamma_sweep_results.csv`. This is a
table/data experiment; it is not an input to `plot_counterexample.py`.
In this sweep, resAA uses the `AndersonAcc` default regularization
`eta=1e-8`, matching the figure runs; pureAA and GlobAA use `eta=0` by default.
The iteration limit for the table experiment is 500.

### 3.2 ENR/ISTA

The required data file is `datasets/ISTA/madelon_train.data.txt`, relative to the
repository root. It is included; see [dataset attribution](datasets/ISTA/README.md).
The labels file is included for provenance but is not read by this experiment.
The second design matrix is generated by the script.

```bash
python 3.2_ENR_ISTA/run_ENR_ISTA.py --dtype float64 --device cpu
python 3.2_ENR_ISTA/plot_ENR_ISTA.py
```

The full run uses `m=1,3,5,10,20,30`, with iteration limits of 2,000 for Madelon
and 25,000 for the synthetic case. It writes `enr_ista_history.csv` and
`enr_ista_summary.csv` under `3.2_ENR_ISTA/results/`. The plotting script displays
the `m=10,20,30` comparisons and writes two residual PDFs under `figures/`.

The full run can take substantially longer than smoke mode. To plot the supplied
results, run only the plotting command.

### 3.3 Nonlinear Helmholtz

```bash
python 3.3_NLH/run_NLH.py --N 2001 --m-values 1,3,5,10,20,30 --max-iters 500 --tol 1e-10 --lambda 0.5 --eta 0
python 3.3_NLH/plot_NLH.py
```

The run writes `nlh_main_history.csv` and `nlh_main_summary.csv` under
`3.3_NLH/results/`. The plot is saved as `3.3_NLH/figures/nlh_residual.pdf`.

### 3.4 Navier–Stokes: three separate runs

The three experiments are run separately because the larger finite-element
problems are time-consuming. Their saved results are in `results_10`,
`results_50`, and `results_100`. The suffix denotes `--base-points`, the number
of points per coordinate direction before edge refinement. Anderson memory is
set independently through `--m-values`.

The settings below are read from each supplied `ns_run_config.json`:

| Result directory | Base points | Reynolds number | Maximum iterations | Function-evaluation limit | Mixed DOFs |
| --- | ---: | ---: | ---: | ---: | ---: |
| `results_10` | 10 | 5,000 | 500 | 1,503 | 2,118 |
| `results_50` | 50 | 8,000 | 500 | 1,503 | 48,422 |
| `results_100` | 100 | 10,000 | 100 | 303 | 190,542 |

All three use `m=10,20,30,50`, tolerance `1e-10`, global relaxation `0.5`,
grad-div parameter `1.0`, edge width `0.1`, edge refinement enabled, and
quadrature order `6`. They differ in Reynolds number and iteration budget as
well as mesh resolution.

Run each command independently, allowing it to finish before starting another
large run:

```bash
python 3.4_NS/run_NS.py --base-points 10 --re 5000 --max-iters 500 --func-eval-max 1503 --m-values 10,20,30,50 --tol 1e-10 --global-lambda 0.5 --grad-div 1.0 --edge-width 0.1 --quadrature-order 6 --output-dir 3.4_NS/results_10
```

```bash
python 3.4_NS/run_NS.py --base-points 50 --re 8000 --max-iters 500 --func-eval-max 1503 --m-values 10,20,30,50 --tol 1e-10 --global-lambda 0.5 --grad-div 1.0 --edge-width 0.1 --quadrature-order 6 --output-dir 3.4_NS/results_50
```

```bash
python 3.4_NS/run_NS.py --base-points 100 --re 10000 --max-iters 100 --func-eval-max 303 --m-values 10,20,30,50 --tol 1e-10 --global-lambda 0.5 --grad-div 1.0 --edge-width 0.1 --quadrature-order 6 --output-dir 3.4_NS/results_100
```

Each run writes a history CSV, a summary CSV, final velocity states in an NPZ
file, and its configuration in JSON. A bare `run_NS.py` invocation uses the
separate default `3.4_NS/results/` directory, so the explicit output paths above
are needed for these three groups.

To plot the three supplied result groups:

```bash
python 3.4_NS/plot_NS_report_basepoints.py
```

It reads all three result directories, compares the `m=50` runs, and writes:

- `3.4_NS/figures/ns_report_basepoints_residual.pdf`
- `3.4_NS/figures/ns_report_basepoints_velocity.pdf`

The residual figure displays iterations 0–100. The velocity plots use the saved
final states. Plotting does not rerun the solvers, although reconstructing the
finite-element mesh and sampling the larger saved states still needs resources.

The bundled `ns_residual.pdf` and `ns_velocity.pdf` can also be viewed directly.
The plotting command above writes separate `ns_report_basepoints_*.pdf` files.

## Numerical notes

Runtime and floating-point results can vary with the machine, numerical
libraries, and thread settings. Use the reference environment above when
comparing results.

- Use `float64`; some regularized coefficient solves do not support `float32`,
  even where that option is exposed by a command-line interface.
- The scalar AA coefficient formula does not guard against an exactly zero
  residual difference. Custom fixed-point maps or parameter choices can
  therefore encounter division by zero and non-finite iterates.

## Saved results

CSV histories and summaries, NPZ final states, and PDF figures are included so
readers can inspect results and regenerate plots without repeating expensive
calculations. The largest result file is the ENR iteration history
`3.2_ENR_ISTA/results/enr_ista_history.csv` (approximately 92.45 MiB).

`.gitignore` excludes editor history, caches, local environments, and
`scratch/`. The supplied datasets, results, figures, and run configurations are
included in the repository.
